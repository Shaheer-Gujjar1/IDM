# Impressive Download Manager (IDM)

<p align="center">
  <b>A blazing-fast, modern, multi-threaded download manager with dynamic connection acceleration, browser interception, and a sleek liquid aesthetic.</b>
</p>

---

## 🌟 Key Features

- **🚀 Multi-Threaded Acceleration**: Dynamic connection splitting downloads files up to 10x faster using concurrent HTTP segment workers.
- **🌐 Seamless Browser Interception**: Auto-detects and captures web downloads & streaming media via Chrome/Firefox browser extension.
- **🎨 Glassmorphic & Modern Design**: Rich liquid animation aesthetics with automatic dark/light theme support.
- **💻 Cross-Platform**: Native desktop performance powered by Tauri v2 and Rust.
- **⚙️ Configurable Download Folders**: System default download directory detection with custom directory picker support.
- **🛡️ Link Refreshing**: Auto-resumes expired or broken download URLs without losing existing progress.

## 📥 Installation

Ready-to-use release binaries for **Windows** and **Linux** are available in the **[Releases Section](https://github.com/Shaheer-Gujjar1/IDM/releases)** on GitHub!

### Download Options
- **Windows**: Download `Impressive.Download.Manager_x64-setup.exe` (NSIS Installer) or `.msi` package.
- **Linux**: Download `.deb` or `.AppImage` package.

Simply run the installer for your operating system and enjoy fast, effortless downloads!

---

## 🔌 Browser Extension Integration

To capture downloads directly from your web browser:
1. Open Chrome/Brave/Edge and navigate to `chrome://extensions`.
2. Enable **Developer Mode** (top-right toggle).
3. Click **Load Unpacked** and select the `browser-extension` folder included with IDM.
